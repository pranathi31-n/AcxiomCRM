# Student Notes

This submission is intended to satisfy the supplied assignment baseline and to be understandable for a student demo/viva.

Implemented in code:
- ASP.NET Core Identity authentication and password hashing
- Password policy and lockout configuration
- Admin / Manager / SalesExecutive roles
- Server-side [Authorize] protection
- Anti-forgery tokens on MVC state-changing forms
- Customer, Lead, Opportunity, Follow-Up and Activity workflows
- Client-side unobtrusive validation and server-side DataAnnotations/business validation
- Duplicate customer email/phone checks
- Opportunity amount/probability/close-date rules
- Follow-up date rule
- Audit logging for important CRM/security-administration actions
- Dashboard KPIs and Chart.js charts
- REST APIs for customers, leads and opportunities
- SQLite database and seed data
- Bootstrap responsive UI

For an academic submission, run and test the application locally and add screenshots/your own documentation if your college requires them. The supplied specification says the final acceptance must demonstrate the application behavior, not merely contain source files.
